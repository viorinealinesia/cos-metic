# Rin's Cosmetic — Premium Beauty & Body Care Edit

Website e-commerce statis untuk **Rin's Cosmetic** dengan desain modern, aesthetic, clean, dan profesional. Vibes premium, feminine, dan elegan (body care & skincare edit).

## Fitur

- **Homepage** modern dengan hero, stats, promo banner, features
- **Katalog produk** dengan search, filter kategori, sort
- **Best Seller** section
- **Product Detail** modal (deskripsi, rating, like, komentar, add to cart/wishlist)
- **Wishlist** (sidebar + localStorage)
- **Shopping Cart** dengan qty control, voucher (RINLOVE15 / RIN10)
- **Checkout via WhatsApp** (otomatis generate pesan order)
- **Beauty Quiz** 3 pertanyaan → rekomendasi produk
- **Customer Reviews**
- **FAQ** accordion
- **Newsletter** subscribe
- **Dark / Light mode** (tersimpan)
- **Floating WhatsApp** yang bisa digeser (draggable)
- **Navbar modern** sticky + mobile menu
- **Favicon** + **Open Graph** meta untuk preview saat share
- Fully **responsive** (mobile & desktop)
- Semua data cart/wishlist/likes/comments disimpan di localStorage

## Cara menjalankan

1. Buka folder ini
2. Buka `index.html` di browser (atau serve dengan Live Server / GitHub Pages)

## Deploy ke GitHub Pages

Push ke repo `rin-scosmetic` → Settings → Pages → Deploy from branch `main` / root.

## Catatan

- Nomor WhatsApp default: `6281234567890` (ganti di `script.js` variabel `WA_NUMBER`)
- Voucher demo: `RINLOVE15` (15%) dan `RIN10` (10%)
- Checkout adalah simulasi front-end via WhatsApp (tidak ada payment gateway)

## Branding

Warna utama: soft rose / terracotta accent + cream / ivory background.  
Font: Cormorant Garamond (heading) + Outfit (body).  
Ciri khas soft, gentle, dan elegan tetap dipertahankan.
